# CoCoCo

Coercion and Copredication as Flexible Frame Composition is the title of a DFG-funded research project lead by Laura Kallmeyer and Rainer Osswald that is being conducted at Heinrich Heine University Düsseldorf.
This page contains the annotated data from the project and other related documents.
Further information about the project can be found at the [CoCoCo project website](https://cococo.phil.hhu.de/), and the details about the annotation can be found in the [paper](https://cococo.phil.hhu.de/)

The annotated data are in the data folder and are named by their content and sources. The files with "copred" in the filenames are copredication sentences and the others include all the annotated sentences.
The files with "positive" in the filename contain the sentences that the automatic classifier classified as having copredications, and files with "negative" in the filename contain sentences that both predicates are labelled the same by the automatic classifier.
The files with "loose" in the filename contain the sentences that the two predicates receive different but intersecting labels.

The document folder now contains the current version of annotation guidelines (August 2025) and an extracted list of predicates with their annotations found in the corpus.
